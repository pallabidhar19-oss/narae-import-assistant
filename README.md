# Narae AI

Narae AI is an AI-powered import assistant built for K-entertainment merchandise logistics.

## Current MVP

- HS Code estimation
- Import duty estimation
- Shipping document guidance
- Customs risk analysis
- AI logistics summary

## Technology

- Python
- Streamlit
- OpenAI API
